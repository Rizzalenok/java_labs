## Задача 1
### Текст задачи
Дробная часть.
Дана сигнатура метода: public double fraction (double x);
Необходимо реализовать метод таким образом, чтобы он возвращал только
дробную часть числа х. Подсказка: вещественное число может быть
преобразовано к целому путем отбрасывания дробной части.
### Алгоритм решения

## Задача 2
### Текст задачи
Сумма знаков.
Дана сигнатура метода: public int sumLastNums (int x);

сложения двух последних знаков числах, предполагая, что знаков в числе не
менее двух.
### Алгоритм решения
1. Находим последнюю цифру числа через остаток от деления на 10 ('x % 10').
2. Находим число, состоящее из двух последних цифр ('x % 100').
3. Вычисляем предпоследнюю цифру, вычитая из двух последних цифр последнюю и деля результат на 10.
4. Складываем предпоследнюю и последнюю цифры и возвращаем результат.

# Задание 2
## Задача 1
### Текст задачи
Модуль числа.
Дана сигнатура метода: public int abs (int x);
Необходимо реализовать метод таким образом, чтобы он возвращал модуль

## Задача 2
### Текст задачи
Безопасное деление.
Дана сигнатура метода: public double safeDiv (int x, int y);
Необходимо реализовать метод таким образом, чтобы он возвращал деление x
на y, и при этом гарантировал, что не будет выкинута ошибка деления на 0. При
делении на 0 следует вернуть из метода число 0. Подсказка: смотри
ограничения на операции типов данных.
### Алгоритм решения
1. С помощью 'if' проверяем, равен ли делитель 'y' нулю.
2. Если равен, возвращаем '0.0'.
3. Иначе приводим делимое 'x' к типу 'double' и выполняем деление 'x / y'.

## Задача 3
### Текст задачи
Тридцать пять.
Дана сигнатура метода: public bool is35 (int x);
Необходимо реализовать метод таким образом, чтобы он возвращал true, если
число x делится нацело на 3 или 5. При этом, если оно делится и на 3, и на 5, то
вернуть надо false. Подсказка: оператор % позволяет получить остаток от
деления.
### Алгоритм решения
1. Сначала проверяем, делится ли число на 15 (т.е. одновременно на 3 и на 5). Если да — возвращаем 'false'.
2. Затем проверяем делимость на 3. Если делится — возвращаем 'true'.
3. Далее проверяем делимость на 5. Если делится — возвращаем 'true'.
4. Во всех остальных случаях возвращаем 'false'.

## Задача 4
### Текст задачи
Строка сравнения.
Дана сигнатура метода: public String makeDecision (int x, int y);
Необходимо реализовать метод таким образом, чтобы он возвращал строку,
которая включает два принятых методом числа и корректно выставленный
знак операции сравнения (больше, меньше, или равно).
### Алгоритм решения
1. Используем конструкцию 'if-else if-else' для сравнения 'x' и 'y'.
2. Если 'x < y', объединяем строку вида 'x + "<" + y'.
3. Если 'x > y', формируем строку со знаком '>'.
4. Иначе (если числа равны) формируем строку со знаком '='.

## Задача 5
### Текст задачи
Тройной максимум.

максимальное из трех полученных методом чисел. Подсказка: идеальное
решение включает всего две инструкции if и не содержит вложенных if.
### Алгоритм решения
1. Инициализируем переменную 'maxNum' значением 'x'.
2. Сравниваем 'maxNum' с 'y'. Если 'maxNum < y', перезаписываем 'maxNum' значением 'y'.
3. Сравниваем обновленный 'maxNum' с 'z'. Если 'maxNum < z', перезаписываем 'maxNum' значением 'z'.
4. Возвращаем итоговое значение 'maxNum'.
